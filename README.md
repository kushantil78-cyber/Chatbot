# 🤖 Simple AI Chatbot

A beginner-friendly chatbot built using **Python** as part of my AI learning journey.

This project demonstrates how AI tools such as **ChatGPT** can assist with coding, learning, debugging, and developing simple applications.

## 📌 Project Overview

The Simple AI Chatbot is a Python-based chatbot that takes user input and provides responses based on predefined topics.

The chatbot can respond to questions related to:

* Python
* Artificial Intelligence
* Machine Learning
* General greetings
* Basic conversations

## ✨ Features

* 💬 Interactive conversation
* 🐍 Built using Python
* 🧠 AI-related responses
* 🔄 Continuous conversation loop
* ⚠️ Handles unknown questions
* 👋 Exit option using `bye`

## 🛠️ Technologies Used

* Python
* ChatGPT
* VS Code
* Git & GitHub

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/AI-Chatbot.git
```

### 2. Open the project folder

```bash
cd AI-Chatbot
```

### 3. Run the chatbot

```bash
python chatbot.py
```

## 💻 Example

```text
You: hello
Bot: Hello! Nice to meet you 😊

You: what is Python?
Bot: Python is a popular programming language used in AI, data science and web development.

You: what is AI?
Bot: AI is the field of creating systems that can perform tasks that normally require human intelligence.

You: bye
Bot: Goodbye! Have a great day! 👋
```
